Architecture

Full architecture

A developer only ever talks to Backstage. Everything after that is Git, and the automation that reconciles it.

  • Git is the system of record. Golden paths open pull requests; a person merges them. Platform intent (Component, Release, Database, DatabaseSchema) and deployment state live in one GitOps repository.
  • The management cluster runs only the platform. Argo CD applies Git to it and reaches out to the workload clusters, which run only services. Nothing in a workload cluster can change the platform.
  • Runtime state flows back. Rollout status, health and metrics from every environment end up in the same portal the request started from.
